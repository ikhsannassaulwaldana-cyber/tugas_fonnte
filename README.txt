TUGAS FONNTE
1. Copy folder ke C:\xampp\htdocs\tugas_fonnte
2. Start Apache dan MySQL.
3. phpMyAdmin -> Import database.sql
4. Buka http://localhost/tugas_fonnte/setup_admin.php
5. Admin: admin@gmail.com / admin123
6. Hapus setup_admin.php setelah admin dibuat.
7. Isi FONNTE_TOKEN dan ADMIN_PHONE di config/config.php.
8. Pastikan extension PHP cURL aktif.
